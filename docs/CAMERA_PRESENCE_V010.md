# v0.10.0 真实到桌检测

用户已确认发布到既有 GitHub Pages；发布结果以对应工作流和线上文件核验为准。未采集用户真实相机或人脸，第一代 iPad Pro/iPadOS16.7.16 尚未实机验收。

## 实现范围

RETURN 新增独立真实摄像头面板，原手动模拟保留并明确标注。默认关闭，刷新不恢复摄像头；用户点击才请求前置摄像头，仅 video，不请求麦克风。勾选「本次检测使用语音问候」后，开启按钮同时允许本页系统语音。

本机 MediaPipe Tasks Vision0.10.21 + BlazeFace short-range float16 v1 CPU 推理。依赖和模型固定版本、同站点提供、构建校验 SHA256；无运行时第三方 CDN。WASM+模型首次约10MB，按需加载/缓存，应用壳安装不预下载整个模型。坐标、特征点、画面不保存、不上传，无 MediaRecorder、身份模板或身份库。相机服务不使用 Railway，摄像头代码不发送画面至通知/飞书后台。

320×240 ideal、5fps ideal/max10fps 采集，约1秒一次推理，耗时高时降低频率；老设备功耗和延迟需实测。页面可见预览；切工作台显示小预览，环境屏时移入环境屏，避免隐藏视频导致 Safari 暂停。允许的页面状态不代表系统一定持续提供画面；无新帧8秒停止。切后台/pagehide/隐私画面/系统结束或静音摄像头/推理失败时释放轨道、关闭模型、清除预览，返回需手动开启。授权弹窗未响应时可关闭，迟到的授权轨道立即释放。

一张人脸置信度≥0.7持续≥3秒、至少3次有效采样才候选到桌；无人连续≥15秒后重新等待；多张人脸不问候。问候冷却默认5分钟，可选1/30/120分钟。短暂遮挡或视频采样间断不构造新到桌。用户免打扰、隐私、编辑/弹窗会阻止问候，解除后稳定检测才补问候。只显示/朗读通用欢迎，不自动展示私人安排。用户主动点击「确认并查看重点」打开已有重点视图；该按钮不构成身份认证。

模型不是身份/活体识别；照片、屏幕上的人脸也可能触发。优化面对镜头的近距离人脸，建议先在0.5–1米、正常光照验收；不能承诺远距离、侧脸、背影或暗光稳定。不得称为主人识别、到家检测、后台摄像头或自动唤醒。既有定时日程提醒不依赖摄像头。

## iPad验收（发布后）

1. 打开正式站，确认v0.10.0 → RETURN。未点击前不应出现相机授权或拍摄状态。
2. 确保未开启RETURN免打扰，保持APP前台与亮屏，勾选本次语音并点击「开启摄像头检测」。本人允许权限，应看到预览和「人脸数/检测耗时」。失败时记录界面错误类别，不发送私人画面。
3. 正对前置摄像头约0.5–1米，持续3秒以上：通用欢迎；继续坐着不应反复问候。点击「确认并查看重点」才打开私人安排。
4. 验收时冷却选1分钟。离开镜头至少15秒，且距上次问候超过1分钟，再回来，确认再次问候。多人同时出现不应触发。
5. 切到工作台/环境屏，检查小预览及关闭按钮；点击关闭应释放相机并隐藏预览。切后台/锁屏也应关闭，回来后不能自动重启。
6. 继续确认系统语音、触控、功耗/发热、持续30分钟稳定性；当前均未真机验收。
