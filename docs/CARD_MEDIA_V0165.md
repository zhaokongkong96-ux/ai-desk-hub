# 今日话题与 AI Radar 卡片图片 · 本地 v0.16.5

按用户提供的三列浅色卡片参考延续现有布局。所有列表卡片（今日话题、AI 每日热榜、Radar 项目库与实时发现）共用 `card-media.js`：上图下文、全宽 16:9 图片区，图片绝对定位并 `object-fit:cover; object-position:50% 50%`，等比放大、居中裁剪。图片区不受原图尺寸或正文长度影响。重点项目仍保留参考图中的左图右文，图片覆盖整个左栏；窄屏恢复上图下文、16:9。

缺图、加载中和加载失败都有填满图片区域的文字封面，不使用不相关的照片。仓库封面标记“项目封面”，今日话题缺图标记“分类封面 · 非报道配图”；真实图片成功加载后再显示“仓库预览／报道配图”，并隐藏底层封面文字，避免透明图片透出重影。

今日话题仅采用 RSS 信息源附带的 `imageURL`：媒体缩略图、图片附件或摘要中的图片，不抓取文章正文、不调用图片代理、不请求付费服务；没有图片的旧数据和收藏继续可用。原有来源、日期、热度依据、失败与历史标注、收藏、加入待办和原文入口保留。
