# v0.12.0 每日使用 · 本机候选

本轮实现用户已指定的第一批功能；尚未公开发布，不调用模型，不增加网络数据服务或权限。线上基线仍为 v0.11.1。

## 使用入口

- 时钟下方“每日使用”：开工/创作/收工流程，重复任务，项目步骤清单。
- 时钟下方“今日 / 明日”：原今日重点与新增明日准备。
- 现有设置中的“导出记录”：新增每日使用数据也纳入用户主动导出的备份。

## 行为

建议流程模板可编辑；手动开始后保存本轮步骤快照，编辑模板不追改已开始或过去的轮次。支持完成、跳过、返回及关联原待办。关联项与原待办共用完成状态；历史日期保留记录。

重复任务支持每天、每周选日和暂停/恢复；在北京时间当天打开/返回页面或前台检查时生成当日实例，不补造关闭期间的过去实例。实例有稳定编号与已生成记录，刷新、重复检查不会重建，删除当天实例后当天不重建。未完成旧任务保留；编辑后续模板不重写已生成实例，可在原待办中编辑单次任务。

项目清单将步骤作为原待办记录保存，在项目视图与原列表共用完成状态，支持新增步骤；步骤的编辑、删除沿用原待办入口。进度按当前仍存在的步骤计算，不自动判断工作完成。

明日准备以北京时间判断日期，过滤示例和已完成日程，包含跨日安排；显示当前读取来源、真实空状态、明确起止的非全天日程重叠、未完成重点待办和明日重复任务预览。准备材料由用户明确填写，按日程编号关联，不编造材料或截止日期。外部日历未读取/不可用时不推断其没有安排。今日重点同样修正为北京时间分日。

## 数据与失败处理

在原 `ai-desk-hub-v1` 中增量增加 `workday` 字段，保留旧 tasks/notes 及其字段；项目与重复实例仍位于 tasks。新操作先写本机存储，成功后替换界面状态，失败保留表单输入供重试。另一页面修改相同存储时提示刷新并阻止继续保存，避免覆盖，不代表多端同步。旧日历、飞书、热榜和音乐连接保持原链路。

原日历源与其他组件仍可能受各自现有保存/读取行为影响；未新增导入恢复或跨设备备份服务。用户实际浏览器与自动化测试浏览器的本机记录相互独立。

- `node scripts/test-workday-ui.cjs`：Chrome 与桌面 WebKit，旧数据、流程与模板编辑、项目状态、重复实例刷新与跨日、明日材料/冲突、写入失败保留输入与重试、导出与四尺寸。使用隔离浏览器合成记录，未访问真实用户账号或调用模型。
- `node scripts/test-workday-offline.cjs`：Chrome 实际安装 v0.12.0 缓存，断网刷新后恢复流程进度并继续本机保存。

- 静态构建与差异空白检查通过；未做真实 iPad 验收或线上发布。
