# 可接续工作的项目卡 · 本地 v0.16.4

## 范围与入口

用户只选择升级现有项目清单。本轮未增加决策中心、成果库、经营复盘或其他提案。

工作台 → 每日使用 → 项目卡与步骤。已有项目直接显示为卡片；缺少上下文时显示未记录，不填入项目记忆中的历史结论。新建、编辑、取消均在原面板内完成。

卡片包含：项目名称、上次已确认结论、一个明确的下一步、结论来源、最多五个继续入口、北京时间的卡片更新时间，以及原有步骤完成进度。网页与对话链接新窗口打开；本机文件仅复制绝对路径，由用户在文件所在电脑打开。不会读取或上传所链接文件。

## 数据与保存

- 保持 `workday.version = 1`、原项目 ID、任务 ID 和 `projectId`。项目增加可选的 `resume: {decision, nextAction, source, links: [{label, target}], updatedAt}`。
- 旧项目只读展示时不迁移写入，不产生假时间。确认内容变化后更新时间；原样保存、打开卡片、步骤完成均不刷新旧上下文时间。
- 下一步是上下文说明，不额外复制成待办。步骤仍使用原任务，共享完成状态。编辑卡片不替换或重新创建步骤；更名只更新对应步骤的项目分类名称。
- 未确认编辑保留在当前页面；后台重绘不清空表单，切换编辑先要求保存或取消。校验错误和本机写入失败保留输入。取消不提交。
- 网页入口仅支持完整 HTTP/HTTPS 地址，拒绝可执行协议、内嵌用户名密码和控制字符。无效外来入口不生成超链接。正文由 textContent 呈现。
- 原备份导出自然包含新增字段。已配对的现有加密同步保留整个项目记录，沿用项目级冲突选择；未开启同步时仍仅保存在本机。不修改同步后端、授权、配对或私有资料。

## 视觉

沿用现有 Rondesign 方向，参考技能内 12、14 的主区与支持区关系：背景继续使用现有青灰画布；项目上下文使用乳白实体面和细边缘，避免重复叠玻璃；结论是正文主区，下一步以窄绿色标记强调，来源、时间和可折叠步骤降低视觉权重。无新图片、装饰图表或虚构效率数据。
