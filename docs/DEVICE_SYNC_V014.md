# v0.14.0 手机与 iPad 受保护同步

用户已选择并授权独立 Cloudflare 免费 Worker＋D1。同步服务已部署；用户已明确授权发布完整 v0.14.0 前端，真实手机/iPad配对未完成。

## 已实现

- 同步待办、记录、本机日程、固定流程模板/日实例、重复模板/已生成标记、项目清单与明确填写的准备材料。
- 飞书只读叠加日程、OAuth/推送凭据、设备定位、媒体、未确认通知草稿不参与。
- 浏览器 AES-256-GCM 加密、空间绑定的认证数据；服务只接收密文，客户端拒绝认证失败或倒退版本。
- 5分钟一次性配对、独立设备凭据、设备列表和撤销；配对内容含解密密钥，须由用户私下转移到自己的设备。
- 旧本机内容先预览数量，可导出备份，勾选确认后合并；稳定ID去重，旧笔记补确定性ID。
- 记录级三方合并，独立修改自动合并；同时修改和删除/修改冲突逐项选择，不静默取最后写入。旧设备重新配对遇到云端删除标记也需确认，不悄悄复活。
- 云端版本条件更新，删除标记随加密内容持久保留。本机多键更新先保存恢复日志，写入中断刷新可恢复，不把半写入当成功。
- 页顶与设置显示本机保存、等待同步、正在同步、已同步、失败/撤销、冲突状态；前台约15秒检查、回到页面重试，编辑期间避免覆盖输入。锁屏不保证持续同步。
- 同步读取的是成功写入本机的内容；本机保存失败或内存与持久记录不一致时不把内存修改上传。

## 用户启用步骤

1. 进入页顶“本机保存”或设置的“跨设备同步设置”。同步服务地址由公开配置填写。
2. 第一台设备填写设备名，预览旧记录、按需导出，勾选确认；从本机私密文件 `sync-service/.private/create-code.txt` 获取创建授权码，创建空间。
3. 在已连接设备生成配对内容，私下复制到另一设备。另一设备也先预览/备份并确认自己的旧记录，再粘贴配对内容合并。
4. 等待状态显示已同步；若有冲突逐项选择。可在设备列表撤销另一台设备，断开本机也会撤销当前服务器访问权。

不要把创建码、配对内容或解密密钥提交到聊天、截图或仓库。同步凭据只存在配对浏览器的本机元数据中；用户主动导出的业务备份不包含同步凭据。
