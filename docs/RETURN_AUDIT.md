## 融合后的使用方式

1. 导航进入RETURN；规则默认北京时间18:00–22:00、冷却2小时。
2. 如当前不在窗口，可将开始与结束都设为00:00并点击保存，使用全天测试；这不会重置已发生的冷却。
3. “模拟到家”通过后，仅显示轻量问候；再点“模拟主人到桌”，显示当前本机未完成任务数量和下一项未完成日程，可进入工作台。
4. 个人摘要只在当前RETURN页面存在：离开页面/切换导航、隐藏页面、重新保存规则、未知身份或展示5分钟后清除。重新模拟仍受规则和冷却约束。
5. “模拟身份不确定”显示全屏通用画面，无个人摘要。点击“结束模拟，返回应用”后恢复应用，这是明确退出演示，非真实认证。
6. 日志最多8条，只含通用事件码、结果理由和时间，不复制待办标题/日程/笔记。清空日志不重置冷却。
