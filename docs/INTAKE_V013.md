# v0.13.0 通知整理 · 文字本机候选

范围：用户要求推进第二批录入减负，先粘贴文字生成可编辑草稿，确认后加入日程或待办；图片、PDF 后续扩展。本轮未引入模型、OCR、文件上传、云端同步或新权限，未公开发布。保留第一批 v0.12.0 每日使用功能与已确认画布布局。

## 使用

底部快速记录栏点击“通知”。可粘贴多项文字，以空行、编号或独立日期段落分开。生成草稿后逐项选择日程或待办，修改名称、北京时间起止与准备材料；核对原文并勾选确认，再保存。可忽略单项，不批量自动入库。底部快速记录已输入文字可带入收集编辑器，不自动读取系统剪贴板。

规则可识别完整年月日、月日（明确提示参考年份）、今天/明天/后天、本周/下周指定星期、常见 24 小时或明确上午/下午时间段，以及明确写出的持续分钟/小时。“周四”不推算是哪一周；缺少结束时间不补默认时长；多个日期、备选时间、无效时间与其他时区保留提示供人工确认。相对日期使用生成草稿时的北京时间日期，不随午夜悄悄变化。

这不是通用语言模型理解，无法保证理解复杂通知、取消通知、否定语句、会议地点、英文或非标准表达。名称可从主题字段或原文首个内容行形成，用户仍需修改。未写明的准备材料保持空白；待办不推算截止时间。图片与 PDF 本轮没有文件选择或识别功能。

## 正式记录和来源

- 草稿在当前页面内存中；关闭对话框后可继续，刷新或关闭页面后未入库草稿不保留，页面已说明。
- 已确认任务进入原 `ai-desk-hub-v1` 的 tasks，保留其他字段及第一批 workday 数据。
- 已确认日程进入原本机日历，时间明确带 +08:00；不写回飞书。日历先持久化成功再加入界面，存储失败不制造可见的假成功记录。
- 每条正式记录保存选定的原文片段、参考日期、确认时间与用户确认的准备材料；不把整份输入自动归档。
- 待办编辑器可查看来源与准备材料；日程编辑器可查看来源，后续编辑仍保留来源。明日准备自动读取导入的准备材料，并允许覆盖编辑。
- 已有同来源或同标题时段的日程、同名待办会提示已有记录并拦截重复创建。同一“明天”通知在不同参考日的事件会按新的实际日期判断。已确认草稿禁用再次提交，连点不会重复入库。
- 来源仅存当前浏览器，跟随用户主动导出；不进入公开 feed、仓库、服务日志。不是跨设备同步。

规则测试覆盖北京时间相对日期/周/跨日、显式时长、无效日期/备选时间/外部时区、批量拆分与材料对应、缺时长和去重。
