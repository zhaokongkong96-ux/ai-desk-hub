# 内容工作室线上交付 v0.17.0

## 用户入口

首页“今日内容选题”摘要 → 内容工作室 → 选题的两个角度/自定角度 → 保存讨论或确认方向 → 研究起草 → 修改并确认脚本 → 提交 Mac 制作 → 播放、通过或退回。

已配对设备自动沿用同一套身份，无需逐台填写 Mac 地址与后台令牌。新设备仍需在工作台完成一次配对。使用同一 GitHub Pages 来源，浏览器和主屏应用的独立存储可能需要分别配对。

## 在线与离线

Mac 每日北京时间 08:00 后采集；休眠后上线补执行。Mac 将当天候选、各选题多个角度和创作进度主动上传到独立 HTTPS 内容服务。首页前台约每分钟检查更新，内容工作室约每 20 秒检查；显示实际采集时间，旧批次明确提示。

Mac 离线时可查看云端已有选题与进度，提交的操作明确等待 Mac，不显示虚假的保存成功。恢复在线后串行处理。版本冲突返回人工处理，不覆盖其他设备已保存的修改。意外中断只补回执，不盲目重复视频制作。首页提示是页面内每日选题入口，不等于关闭浏览器后仍推送系统通知。

## 私有后台

- 独立 Worker/D1：`ai-desk-hub-studio`。只查询原同步数据库的设备身份，不读取或修改原工作台记录；选题和创作数据使用新数据库。
- 云端快照、命令正文、处理结果和视频块使用 AES-GCM 加密存储。密钥仅在 Worker Secrets，Mac 机器令牌仅在本机私有配置和 Worker Secrets。属于服务端加密，不能称为浏览器到 Mac 的端到端加密。
- 浏览器仅使用本设备已有配对令牌，经 HTTPS 验证所属工作台；未配对、其他工作台和被撤销设备拒绝访问。令牌与密钥不放在网页配置或 URL 中。
- 原始脚本、素材和视频仍保存在 Mac；云端自动预备最近两条可审核成片。旧成片点击播放可请求补传。云端审核副本按最近使用情况控制在 350MB 内，Mac 原片不删除。
- 使用已有免费方案，不开通付费服务。容量依据 [D1 Free 单库限制](https://developers.cloudflare.com/d1/platform/limits/) 预留余量；超过服务配额会报错，不擅自升级。

## Mac 运行与回滚

运行副本：`~/Library/Application Support/AIContentStudio`。LaunchAgent `com.aideskhub.content-studio` 继续运行原 FastAPI 与每日采集，新增 `remote_bridge.py` 主动连接云端，无新入站端口或临时隧道。

私有配置在 `data/remote/config.json`，不得上传仓库。设 `enabled=false` 并重启原 LaunchAgent 可停止远程桥接，本机工作室和数据保留。启用前 SQLite 使用一致性备份，原页面和发布源文件也已备份；回滚前应检查是否有未处理操作。

## 验证

已通过真实云端双设备身份读取今日 10 个选题、3 个重点候选，每题两个角度；经云端命令到 Mac 保存原审核状态，再由另一设备读取。旧版本编辑被拒绝，实际内容不改动。12.48MB A2 成片远程下载与 Mac 原片 SHA-256 一致，临时验证身份已删除。A1/A2 审核副本均已上传就绪。

独立测试包括未配对/其他工作台/撤销访问隔离、加密存储、重复请求、失败回执不重复生产、视频完整性和容量轮换。浏览器工具当前报告本地浏览器使用关闭，真实页面点击及 iPad 真机结果待独立确认，不能以 API 通过替代。
