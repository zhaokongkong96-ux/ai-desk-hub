## 每日热榜规则（2026-10-30，每日自动发布）

AI RADAR 顶部新增每日热榜，原项目目录保留。候选来自 GitHub Trending 每日页与近期更新的 AI / LLM 主题仓库；排序使用近期 Star 增长与近 7 天更新且有评论的 Issue / PR 数，累计 Star 不参与热度分。讨论指标不等于新增评论或 Discussions 活动。

热度分为 `3 × log(1 + 日均新增 Star) + 2 × log(1 + 活跃线程数)`；新发现的稳定主版本 x.0.0 发布加 3 分，7 天内重复且无重大更新则乘 0.35。最多展示 6 项，不用无可验证热度的旧项目补齐。官方每日榜的新增量优先，否则使用至少间隔 6 小时的两次采集差值并注明真实间隔；初次采集不估算增量。
