# AI Desk Hub v0.4.0

延续原v0.3应用。参考 Third Screen 的深色固定分区，加入真实 FullCalendar 标准组件。保留现有待办、笔记和 AI RADAR，不迁移到新的应用框架。

## 可体验功能

- 工作台：日历、大时钟、下一项日程、待办、笔记、专注计时、待接入简报。12.9英寸横屏参考1366×1024，核心分区一屏显示；数据多时区域滚动。
- 日历：日/周/月切换，上一页/下一页/今天，点空白时段新增、选范围新增、点事件编辑、确认删除、拖动/拉伸调整时间。放大日历可使用更大的编辑区域。
- 日程保存在本机浏览器；首次提供三条带“示例”标记的当日日程。修改后成为本机日程。Apple/Google日历尚未连接。
- 专注计时：开始/暂停/重置/休息，刷新后恢复当前状态。没有锁屏后台系统通知保证。
- 底部快速记录：原有待办和笔记继续保留，中文输入组合期间的回车不会提交；输入/选择热区扩大，键盘偏移通过visualViewport调整。
- JSON导出包含待办、笔记、日历事件；尚无导入恢复功能。
- AI RADAR保留精选库、本地过滤、手动GitHub公开搜索和加入待办。AI简报尚未接入模型。

## 本地启动与发布产物

```sh
node scripts/prepare-site.mjs
python3 -m http.server 8766 --bind 127.0.0.1 --directory _site
```

使用 `http://localhost:8766/`，不要用file://检查PWA。应用无需npm安装；FullCalendar 6.1.19本地分发文件和MIT许可随项目提供，无运行时CDN依赖。详见 `THIRD_PARTY_NOTICES.md`。

构建脚本校验JS/manifest/种子结构/图标尺寸，只复制白名单资源。兼容GitHub Pages仓库子路径。更新资源时需修改sw.js缓存版本。

## 验证与限制

本轮Chrome和桌面WebKit验证：原有数据保留、日历CRUD/错误时间校验、实际鼠标拖动并持久化、日周月视图、中文组合回车保护、待办完成与刷新、运行及暂停计时刷新恢复、含日程的导出、模拟Radar搜索与加入待办、五尺寸两页面无横向溢出。真实设备的长按拖动、软键盘及iPadOS16.7.16仍待实测。

Chrome另测根路径与仓库子路径：首次在线缓存后断网刷新，日历可新增和切换视图。这里的WebKit是当前桌面引擎，不是iPadOS16.7的Safari，也未模拟真实硬件性能。

目标设备：用户称12.9英寸、可能为第一代，iPadOS16.7.16。当前仓库尚未公开推送/部署，本地修复在codex/pages-readiness。GitHub Actions和线上HTTPS待实际运行验收。

## 数据与边界

旧待办/笔记仍使用 `ai-desk-hub-v1`，新日历使用 `ai-desk-hub-calendar-v1`，专注计时使用 `ai-desk-hub-focus`。均为当前浏览器localStorage，Safari和主屏幕应用数据共享需实机确认。定期导出备份。不要将私人数据或密钥提交到公开仓库。

无外部日历同步、账号云同步、后台采集、LLM简报、全天常驻或实体硬件验收。项目示例和公开仓库线索不能当作已核验的许可/成本/可复现性。
