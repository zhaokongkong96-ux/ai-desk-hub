# AI Desk Hub v0.6.5

延续原v0.3应用。参考 Third Screen 的深色固定分区，加入真实 FullCalendar 标准组件。保留现有待办、笔记和 AI RADAR，不迁移到新的应用框架。

## 环境屏横构图壁纸（v0.6.5）

取消几何主题，内置油画与自然各5幅，原图均为横构图。油画为梵高《麦田与柏树》、毕沙罗《冬日清晨的蒙马特大道》《蓬图瓦兹的雅莱山》、丘奇《安第斯之心》、比尔施塔特《落基山脉：兰德峰》；自然为森林、山湖、雾山、沙丘、海浪。替换了旧版竖构图图片，未将竖图裁成横图。来源/作者/许可/实测尺寸见 wallpapers.js 与 THIRD_PARTY_NOTICES.md。

保留上一张/下一张、分类记住选择、刷新恢复、来源链接、自己的画作与离线缓存。旧版“几何”偏好自动回到油画；已移除的图片偏好自动选用该分类第一幅。构建校验两类各5幅及JPEG真实宽度大于高度。油画完整显示，照片铺满；首次完整载入后支持离线使用。Chrome与桌面WebKit已验证10张图片的实际尺寸/加载、两类各5幅循环切换、刷新恢复、旧偏好迁移，以及4种屏幕尺寸；Chrome离线刷新和10张图片逐张切换通过。此版本仅本地，未公开发布，真实iPad验收待完成。

## 网易云 App 入口（v0.6.3）

音乐卡主按钮改为“打开网易云音乐”，通过用户点击的`orpheus://`链接尝试唤起已安装的App，不需要歌单链接或网易云账号授权。原官方网页播放器和本地音频保留在“更多播放方式”。不自动唤起、不自动跳商店、不检测安装成功，也不读取或控制网易云App的播放状态。唤起前暂停本页音频并卸载官方iframe，避免本页和App同时发声。

协议依据：网易云官方移动页面及其官方移动JS中的`ORPHEUS_SCHEME`。当前尚未在用户的iPad/网易云具体版本上验证，按钮只显示“已请求打开”而非“已打开”。

## 横屏收尾（v0.6.2）

工作台在1366×1024下移除底部2px额外滚动。只调整工作台外层底部留白，日程位置/尺寸、六个面板和三个主入口不变；AI RADAR不应用此条样式。真实iPad与外部服务接入状态仍按下文的未验收项处理。

## 前台提醒与保存反馈（v0.6.1）

设置中可开启重要日程提前10分钟的前台轻提示，默认关闭；排除示例、全天和已完成日程，遵守RETURN免打扰，编辑/弹窗/隐私画面不打断，每个事件开始时刻仅提示一次。不使用系统通知或锁屏保证。

保存失败时明确提示仅当前页面有效，记录编辑器保留并可重试；导出可备份当前内存数据。新增捕获/修改不再在写入失败时声称已保存。已用Chrome和桌面WebKit验证免打扰、输入保护、去重、刷新与写入失败/重试。网易云真实公开官方播放器可加载榜单和曲目，用户歌单播放仍未验收。

## Companion V2 体验对接（v0.6.0）

保持上方日程与AI RADAR内容/排版不变。新增环境屏（3个内置抽象主题、本机图片、前台闲置切换），原专注卡替换成音乐卡，提供网易云官方外链播放器入口及可实际播放本地音频的播放器。首页没有增加一排新页面。旧专注数据保留，计时UI/运行逻辑移除。

待办可编辑和标记重点，笔记可编辑/确认删除；无ID旧笔记可直接使用。所有本机记录仍沿用原键。今日重点是本机规则摘要，不是LLM生成；示例日程不计入。RETURN恢复快速记录入口；环境屏通过“记录想法”退出到同一记录栏。

天气按需请求浏览器定位，以2位小数坐标查询Open-Meteo当前天气；前台每15分钟更新，仅保留本次会话。可停止、拒绝定位、处理网络错误。真实公开API结构验证和模拟定位测试不等于用户iPad定位验收。

用户已选择飞书日历、网易云音乐、当前位置天气。飞书尚未授权；网易云官方播放器入口HTTP可达，但用户歌单及会员/版权/嵌入实际播放尚未验收，不可读取或遥控iPad上的网易云App。暂无摄像头、人员识别、语音转写、模型摘要或后台热点采集。公开部署和真实iPad验收均未完成。

本轮Chrome/桌面WebKit的记录编辑/重点、刷新保存、导出、媒体音频、环境切换、定位成功/拒绝/网络错误的模拟测试与四尺寸检查通过；Chrome离线壳通过。网易云URL转换测试使用替身，真实歌单播放待验证。

完整对接表、仍需用户补充的信息、后续顺序见[Companion V2对接方案](docs/COMPANION_V2_ALIGNMENT.md)。

## 本地启动与发布产物

```sh
node scripts/preview.mjs
```

使用 `http://localhost:8765/ai-desk-hub/`，保持进程运行。启动脚本会先重新构建，只监听本机并只提供`_site`内的公开静态文件，不提供源码/交接包/目录列表。可用`--port 8766`选择其他本机端口（端口改变会变成另一浏览器数据来源）；原端口保持不变可继续使用已有记录。不要用file://检查PWA。应用无需npm安装；FullCalendar 6.1.19本地分发文件和MIT许可随项目提供，无运行时CDN依赖。详见 `THIRD_PARTY_NOTICES.md`。

构建脚本校验JS/manifest/种子结构/图标尺寸，只复制白名单资源。兼容GitHub Pages仓库子路径。更新资源时需修改sw.js缓存版本。

## 验证与限制

本轮Chrome和桌面WebKit验证：原有数据保留、日历CRUD/错误时间校验、实际鼠标拖动并持久化、日周月视图、中文组合回车保护、待办完成与刷新、运行及暂停计时刷新恢复、含日程的导出、模拟Radar搜索与加入待办、五尺寸两页面无横向溢出。真实设备的长按拖动、软键盘及iPadOS16.7.16仍待实测。

Chrome另测根路径与仓库子路径：首次在线缓存后断网刷新，日历可新增和切换视图。这里的WebKit是当前桌面引擎，不是iPadOS16.7的Safari，也未模拟真实硬件性能。

目标设备：用户称12.9英寸、可能为第一代，iPadOS16.7.16。当前仓库尚未公开推送/部署，本地修复在codex/pages-readiness。GitHub Actions和线上HTTPS待实际运行验收。

## 数据与边界

旧待办/笔记仍使用 `ai-desk-hub-v1`，新日历使用 `ai-desk-hub-calendar-v1`，历史专注计时使用 `ai-desk-hub-focus`（当前不再运行），体验偏好使用 `ai-desk-hub-companion-v1`。均为当前浏览器localStorage，Safari和主屏幕应用数据共享需实机确认。定期导出备份。不要将私人数据或密钥提交到公开仓库。

无外部日历同步、账号云同步、后台采集、LLM简报、全天常驻或实体硬件验收。项目示例和公开仓库线索不能当作已核验的许可/成本/可复现性。
